# 🏦 Mini Banking System in C

## 📌 Description
This project is a simple simulation of a banking system developed in C as an academic exercise.

The program allows a user to manage a bank account through a menu-driven interface. It is designed using modular programming with functions and procedures.

---

## ⚙️ Features

The system allows the user to:

- 💰 Deposit money into the account
- 💸 Withdraw money (with balance validation)
- 📊 Display current balance
- 🚪 Exit the program

---

## 🧠 Concepts Used

- Functions and procedures
- Passing parameters by reference (pointers)
- Conditional statements
- Loops (while / do-while)
- Menu-driven programming
- Basic error handling
